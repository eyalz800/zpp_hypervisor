  delivery_time - expiration_time is only a latency if both fields are on the same
  clock. For a one-shot arm expiration_time is the deadline the GUEST computed and
  delivery_time is the level above's reference counter; this VMM publishes its own
  reference-TSC page to the guest, so they need not share an epoch. Sample the pair
  twice a minute apart: constant = epoch skew, growing = rate divergence, jittering
  = a real latency. A value stable to four decimals is NOT a latency.
